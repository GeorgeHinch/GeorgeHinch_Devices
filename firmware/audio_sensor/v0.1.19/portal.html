Distance sensors

One or two VL53L0X modules trigger the washing sequence.

Sensor 1 Entrance sensor · I2C address 0x2A
Sensor 2 Exit sensor · I2C address 0x2B
Automatic calibration uses 25 stable clear-track readings to set each occupied threshold. Leave the track clear when calibrating. Sensor availability is checked during startup; restart after plugging in or removing a module.

External outputs

Crossing-light outputs available to JMRI through MQTT.

SIGNAL_OUTPUT_1_174HC595 QA · D1 · Crossing Lamp 1
SIGNAL_OUTPUT_1_274HC595 QB · D2 · Crossing Lamp 2
JMRI controls these through the device crossing command. The two outputs follow the selected Alternating or Strobe Together pattern; the light-only command keeps the outputs active while muting audio playback.
